# Stage 1 Codebook

This codebook describes the frozen respondent-level dataset. Construct scores will be created in Stage 3.

## Response coding

| Value | Meaning |
|---:|---|
| 1 | Strongly Disagree |
| 2 | Disagree |
| 3 | Neither Agree nor Disagree |
| 4 | Agree |
| 5 | Strongly Agree |

## Administrative and profile variables

| Variable | Meaning |
|---|---|
| response_id | Anonymous record identifier; source prefix is Manual or Digital. |
| source | Collection mode: paper questionnaire or Google Forms. |
| Q2_age_group | Respondent-selected age category. |
| Q3_length_of_service | Respondent-selected Union Bank service category. |
| Q4_job_level | Respondent-selected job-level category. |
| imputation_count | Number of documented within-construct item imputations. |
| flag_count | Number of retained record flags. |
