# V5 Respondent Profile Summary

The [Excel workbook](outputs/v5-profile-summary/profile-frequencies.xlsx) contains formula-driven frequencies and percentages for age group, length of service, and job level. Each profile total is 102, and each percentage uses 102 as its denominator. The workbook includes the 102 anonymous source rows so the formulas can be checked in Excel.

The source is `03-scored-dataset/final-analysis-data.csv`, which contains 103 profile-complete records. This workbook omits `Digital-01` to make the 102-record subset requested for Version 5. The original CSV is unchanged.

**Reconciliation boundary:** The saved SPSS output reports 102 valid regression cases but does not identify the excluded response ID. Therefore, this Excel subset is traceable to the requested exclusion, but its exact person-level match to the SPSS regression sample remains unverified without the SPSS case file. Keep this note with the workbook when considering whether to insert its profile table into the thesis.
