# Stage 3 Scored Dataset

This folder contains the final respondent-level dataset for the 105 eligible records retained in Stage 1. It is the input for descriptive analysis, reliability checks, correlations, and the two planned regression models.

## Files

- final-analysis-workbook.xlsx: formula-driven workbook with source data, eligibility audit, codebook, and construct scores.
- final-analysis-data.csv: SPSS-ready respondent-level dataset including the four construct means.
- final-analysis-codebook.md: variable definitions and scoring rules.
- final-analysis-spss-syntax.sps: import and analysis syntax for SPSS.

## Scoring

Hybrid Learning is the arithmetic mean of HL1–HL7. Trainer Competence is the arithmetic mean of TC1–TC6. Learner Engagement is the arithmetic mean of LE1–LE6. Training Effectiveness is the arithmetic mean of TE1–TE7. Higher values indicate more positive reported perceptions.

The dataset contains two documented imputed item values already approved in the data-cleaning record. It does not remove repeated anonymous patterns or impute missing profile fields. It standardises only equivalent age and service-label variants for descriptive tables; the Stage 1 freeze retains the original entries.

Stage 3 creates scores only. It does not report reliability, correlations, regression results, hypothesis decisions, or Chapter 4 findings.
