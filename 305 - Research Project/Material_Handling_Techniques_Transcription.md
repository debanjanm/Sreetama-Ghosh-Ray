## Method Comparison: Material Handling Project and Sreetama’s Study

> **Note:** This section is a project-specific comparison added after the source transcription. It is not part of the original Material Handling project.

Sreetama Ghosh Ray’s study, *Hybrid Learning and Training Effectiveness at Union Bank of India*, uses 103 profile-complete responses and four scored constructs: Hybrid Learning, Trainer Competence, Learner Engagement, and Training Effectiveness. Its analysis is deliberately limited to techniques that answer its three relationship hypotheses.

| Technique | Used in Material Handling project | Used in Sreetama’s study | Reason for use or non-use in Sreetama’s study |
| --- | --- | --- | --- |
| Frequencies and percentages | Yes | Yes | They describe the respondent profile, response disposition, and five-point item-response patterns. |
| Mean and standard deviation | Yes | Yes | They show the average perception and spread of responses for each item and construct. |
| Bar charts | Yes | Yes | They make profile and item-response distributions easy to review. |
| Cronbach’s alpha | Yes | Yes | It checks internal consistency separately for the four questionnaire constructs. |
| Pearson correlation | Yes | Yes | It is the main test for the three hypotheses, each of which asks about a relationship between construct scores. |
| Multiple regression | Yes | Yes | Hybrid Learning and Trainer Competence are entered together as predictors of Learner Engagement. |
| Simple regression | Not clearly separated | Yes | Learner Engagement is tested as the single predictor of Training Effectiveness. |
| Tolerance and VIF | Yes | Yes | They check predictor overlap in the two-predictor regression model. |
| Chi-square test | Yes | No | Chi-square tests associations between categorical variables. Sreetama’s hypotheses use averaged construct scores, so Pearson correlation retains more information. |
| Independent-samples t-test | Yes | No | The study has no hypothesis comparing two defined respondent groups. |
| One-sample t-test | Yes | No | The study does not test a construct mean against a fixed benchmark or midpoint. |
| One-way ANOVA | Yes | No | Age, service length, and job level describe the sample; the research objectives do not test group differences. |
| Factor analysis | Yes | No | The questionnaire has four theory-led constructs. This is a relationship study, not a large-sample scale-development study. |
| KMO, Bartlett’s test, communalities, scree plot, and component plot | Yes | No | These are factor-analysis checks and outputs, so they are unnecessary without factor analysis. |
| Cochran’s Q / “ANOVA with Cochran’s” | Yes | No | It is not an appropriate reliability test for this five-point Likert questionnaire. Cronbach’s alpha is the relevant reliability measure. |
| Multilayer perceptron / neural network | Yes | No | It is not needed for the theory-led, 103-response HRM study and would be harder to explain than regression. |
| Durbin–Watson statistic | Yes | No | It is mainly relevant for serially ordered observations. This study uses one-time, cross-sectional survey responses. |
| P–P plot and scatterplot | Yes | Not reported as a main result | They may be used internally to inspect regression assumptions, but they do not test a research hypothesis. |
| Formal mediation or SEM | No | No | The study is cross-sectional and tests associations, not a formal indirect causal effect. |

### Techniques Used in Sreetama’s Study

```text
Respondent and item description
→ Cronbach’s alpha for each construct
→ Pearson correlation for H1, H2, and H3
→ Multiple regression: Hybrid Learning + Trainer Competence → Learner Engagement
→ Simple regression: Learner Engagement → Training Effectiveness
```

This approach matches the study’s objectives and keeps the analysis understandable. It avoids adding statistical tests that do not answer the research questions.
