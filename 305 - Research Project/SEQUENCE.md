# SEQUENCE.md — Canonical Chapter/Version Tracker

This file says which version of which chapter folder is **current** right now, and logs why each version bump happened. When you refine a chapter (add a new version-N folder), update this file in the same edit — a version folder that isn't logged here doesn't count as canonical yet.

**Chapter definitions** (folders now match the official department chapter numbers, per student's request — previously organized by work-type as `stage-0` through `stage-4`; that structure is retired, mapping given below):
- **chapter-0** — Informal, not a submitted chapter: topic framing, guide's suggestion, first-principles concept breakdown, terminology glossary.
- **chapter-1** — Introduction.
- **chapter-2** — Review of Literature.
- **chapter-3** — Research Methodology. Has two independent sub-tracks, each with its own version history: `objectives-and-hypotheses/` and `questionnaire/`.
- **chapter-4** — Data Analysis and Interpretation. (Not started — needs real survey data first.)
- **chapter-5** — Conclusion. (Not started — depends on chapter-4's results.)

`stage-0` → `chapter-0` · `stage-1` → `chapter-2` · `stage-2` → `chapter-3/objectives-and-hypotheses` · `stage-3` → `chapter-3/questionnaire` · `stage-4` (data analysis half) → `chapter-4` · `stage-4`/`stage-5` (conclusion half) → `chapter-5`.

## What triggers a version bump

Bump a chapter/sub-track to the next version-N (new folder, e.g. `chapter-3/questionnaire/version-3/`) when:
- A supervisor/guide correction changes the actual content (not just wording polish — that can stay in-place within a version).
- A model or scope decision lands that changes the content of that chapter/sub-track.
- A pilot test or data-collection result forces a redesign.

When you bump a version: copy the folder, make the edits, then add a row to **Current canonical state** above and a numbered entry to **Sequence log** explaining what changed and why. Leave the old version folder in place — don't delete it, it's your audit trail if a panel asks "did this change" or you need to revert.
