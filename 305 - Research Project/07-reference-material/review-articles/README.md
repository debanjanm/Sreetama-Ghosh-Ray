# Article Collections for Thesis Version 2

This folder separates the literature used to develop the Version 2 study on **Hybrid Learning and Training Effectiveness**. The two collections support the two variables in the approved model:

```text
Hybrid Learning → Training Effectiveness
```

Each collection contains a literature matrix and a record of the available full texts. The matrices distinguish between journal articles, scale-development studies, dissertations, and official organization documents. A source is used only for the purpose recorded in its matrix.

- [Hybrid Learning collection](hybrid-learning/README.md)
- [Training Effectiveness collection](training-effectiveness/README.md)

The original six-construct research history remains under `01-current-thesis/` and is not the source of Version 2 chapter text or questionnaire items.
