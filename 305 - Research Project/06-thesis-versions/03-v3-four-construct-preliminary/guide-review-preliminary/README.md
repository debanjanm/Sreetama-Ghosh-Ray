# Preliminary Guide-Review Pack

This folder contains the interim analysis of the first Google Forms export for the study Hybrid Learning and Training Effectiveness at Union Bank of India. It is intended for discussion with the academic guide. It does not replace the approved Chapter 3 or the final Chapters 4 and 5.

The export has 24 submitted records. Two respondents selected No to the eligibility question, so the preliminary analysis uses 22 eligible records. The planned final sample remains approximately 80 eligible employees.
