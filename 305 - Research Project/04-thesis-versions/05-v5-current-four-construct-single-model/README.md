# Version 5 — Hybrid Learning and Training Effectiveness at Union Bank of India

Version 5 is a separate Markdown thesis version built from the supplied SPSS Statistics 23 output. Version 4, the original 103-record dataset, and existing Word and PDF drafts remain preserved.

## Study Model

```text
Hybrid Learning ────────┐
Trainer Competence ─────┼──→ Training Effectiveness
Learner Engagement ────┘
```

Hybrid Learning, Trainer Competence, and Learner Engagement are the independent variables. Training Effectiveness is the dependent variable. Learner Engagement is treated as a separate predictor, not as a mediator.

## Analytical Basis

The Version 5 result source is the [SPSS output freeze](../../05-research-data-and-analysis/07-v5-spss-output-freeze/README.md). The supplied output reports a multiple-regression analysis with 102 valid cases. It is not a case-level raw-data file.
