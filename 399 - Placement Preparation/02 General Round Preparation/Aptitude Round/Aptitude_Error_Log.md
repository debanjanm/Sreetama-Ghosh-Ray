# Aptitude Error Log and Progress Tracker

A mistake you write down is a mistake you fix. Use this file after every practice set, topic drill and mock test.

## How to use this log

1. After any practice, copy each **wrong or skipped** question into the Error Log table below. Also log questions you got right by guessing.
2. Pick the **error type** (see the key). The type matters more than the topic, because it tells you what to fix.
3. Write the **correct method in your own words**, not just the answer.
4. Set the **retry dates**: redo the question after 1 day, 3 days and 7 days without looking at the method. Tick each retry when you get it right.
5. Once a week, update the Topic Tracker and the Mock Score Tracker and read the Weekly Review checklist.

## Error type key

| Code | Type | What it means | Usual fix |
|---|---|---|---|
| **C** | Concept gap | You did not know how to approach it | Re-read the topic file ('In simple words' first), then redo it |
| **F** | Formula recall | You knew the idea but forgot the formula | Add it to the formula sheet and recite it daily |
| **A** | Arithmetic slip | The method was right but the calculation was wrong | Practise tables, squares, fractions; write steps neatly |
| **R** | Misread | You answered a different question than the one asked | Underline what is asked (amount vs interest, profit vs profit percent) |
| **T** | Time pressure | You ran out of time or skipped | Practise with the target time shown at the top of each topic file |
| **G** | Guess | You guessed and may have been lucky | Treat it as wrong and revise the topic |

## Weekly Review Checklist

- [ ] Update the Topic Tracker from this week's practice.
- [ ] Find the 3 topics with the lowest accuracy and re-read their files.
- [ ] Count which error type (C, F, A, R, T, G) appears most. Fix that habit first.
- [ ] Redo every error-log question whose retry date has arrived.
- [ ] Take one timed section or full mock and record the score.
- [ ] Add any new formula you forgot to the [Formula and Mental Math Sheet](Topics/01%20Quantitative%20Aptitude/00_Formula_and_Mental_Math_Sheet.md).
- [ ] Check the employer's test notice for pattern, timing and negative marking, and adjust practice.

## Patterns to watch for

- Many **R** errors: slow down for the first ten seconds of each question and underline the ask.
- Many **A** errors: practise squares, cubes and fraction-to-percent daily for ten minutes.
- Many **T** errors: use the target time in each topic file and skip early, then return.
- Many **G** errors: attempt fewer questions with more care when negative marking applies.
- A section stuck in Red for two weeks: go back to the 'In simple words' part and the easy patterns before the hard ones.
