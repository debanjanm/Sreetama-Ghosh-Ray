# Quadratic Equation Comparison (x vs y)

> **Difficulty:** Medium  ·  **Target time:** 60 s

## Rules and formulas
- Factor each equation to get all roots of x and all roots of y.
- Compare **every** root of x with **every** root of y (four pairs for two roots each).
- If every pair gives the same relation, that is the answer. If some pairs are > and some are =, answer x ≥ y (similarly x ≤ y). If pairs conflict (some > and some <), answer "no relation".
- Splitting the middle term: for ax²+bx+c, find two numbers with product ac and sum b.
- x² = k gives x = ±√k, so a perfect-square equation always has a negative root.

## Recognise the pattern
Two equations, one in x and one in y, followed by "x > y, x ≥ y, x < y, x ≤ y, or no relation". This is a pure root-comparison task, not an algebra word problem.

## Solve
1. x²−5x+6=0 gives x = 2, 3; y²−7y+12=0 gives y = 3, 4. Pairs: (2,3)<, (2,4)<, (3,3)=, (3,4)< → **x ≤ y**.
2. x²=16 gives x = ±4; y²−3y−4=0 gives y = 4, −1. Pairs: (4,4)=, (4,−1)>, (−4,4)<, (−4,−1)< → **no relation**.
3. x²−10x+24=0 gives x = 4, 6; y²−5y+4=0 gives y = 1, 4. Pairs: (4,1)>, (4,4)=, (6,1)>, (6,4)> → **x ≥ y**.

## Tips and traps
Write roots on a number line instead of comparing in your head. Do not drop the negative root of x² = k. If the discriminant b²−4ac is negative the roots are not real; follow the instructions in the question. For x² + bx + c = 0 with c > 0, the roots share a sign: both positive if b < 0 (like x²−5x+6), both negative if b > 0 (like x²+5x+6). If c < 0, the roots have opposite signs.

## Try it
1. x²−7x+10=0 and y²−5y+6=0. **Answer:** x = 2, 5; y = 2, 3 → no relation.
2. x²+5x+6=0 and y²−1=0. **Answer:** x = −2, −3; y = ±1 → x < y.
3. x²−9x+20=0 and y²−11y+30=0. **Answer:** x = 4, 5; y = 5, 6 → x ≤ y.
