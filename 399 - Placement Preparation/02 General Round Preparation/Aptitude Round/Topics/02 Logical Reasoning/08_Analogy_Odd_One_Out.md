# Analogy and Odd One Out

> **Difficulty:** Easy to Medium  ·  **Target time:** 30 s

## In simple words

**The idea:** Work out how the first pair is connected, then find the option connected in the same way.

**Think of it like:** 'Doctor : Hospital' and 'Teacher : School' are both 'person : place of work'.

**Simple steps:**
1. Say the relationship in a short sentence.
2. Test each option against that exact sentence.
3. Throw away options that only share the topic but not the relationship.

**Watch out:** Belonging to the same topic is not the same as having the same relationship.

## Method
Describe the first relationship as a precise sentence: part-of, tool-for, cause-of, synonym, opposite, sequence, or degree. Apply that relationship to each option.

## Recognise and solve
1. “Thermometer : Temperature :: Barometer : ?” Instruments measure quantities; answer **pressure**.
2. “Seed : Plant :: Egg : ?” A seed may develop into a plant; an egg may develop into an **animal/bird**, depending on choices. Pick the relationship as constrained by options.
3. Odd one among square, triangle, circle, cube: **cube**, the only 3D solid.

## Tips and traps
A different criterion could also make an item odd; state the common property shared by the other three. Avoid choosing merely because terms belong to the same broad category.

## Try it
“Author : Book :: Composer : ?” **Answer:** music/composition.

## More worked patterns

### Pattern 1: Book : author :: painting : ?

**Solution:** A book is created by an author; a painting is created by an **artist**. State the relation before matching.

### Pattern 2: Choose the odd one: triangle, square, pentagon, circle.

**Solution:** **Circle**: the other three are polygons with straight sides. “All are shapes” is too broad to distinguish them.

### Pattern 3: Seed : plant :: egg : ?

**Solution:** A seed develops into a plant; an egg develops into an **animal** (or chick if the question specifies a hen). Match development, not merely association.

## Deeper patterns (medium to hard)

### Extra rules and tricks
- Common relationships: synonym, antonym, part-whole, tool-use, worker-workplace, cause-effect, producer-product, degree, symbol-meaning, young-adult.
- Number analogies: look for squares, cubes, doubles or add-and-multiply patterns (4:16 :: 5:25).
- Letter analogies: check reversal, shift, or position patterns (CAT : TAC :: DOG : GOD).
- Odd one out: find the property shared by three, then confirm the fourth fails it.

### Medium patterns

**M1. Pen : Write :: Knife : ?**

**Solution:** Tool and its use: **Cut**.

**M2. 8 : 64 :: 5 : ?**

**Solution:** 8² = 64, so 5² = **25**.

### Hard patterns

**H1. Drought : Famine :: Vaccination : ?**

**Solution:** Cause and effect: a drought causes famine; vaccination causes **immunity**.

**H2. Odd one out: 8, 27, 64, 100, 125.**

**Solution:** 8, 27, 64 and 125 are perfect cubes. **100** is not.
