# Placement Tracker

One place for every company, deadline, round, contact and offer. Update it the same day something changes. If it is not written here, treat it as not done.

**Last updated:** 2026-10-28

## How to use this file

1. Add a row to the **Company Tracker** as soon as you hear about an opening, even before you apply.
2. Put every deadline and test date in the **Upcoming Dates** table so nothing is missed.
3. After each round, fill the **Round Log** while you still remember the questions. These notes feed the aptitude [error log](../02%20General%20Round%20Preparation/Aptitude%20Round/Aptitude_Error_Log.md) and the HR interview practice.
4. Record which resume version you sent in the **Resume Version Log**, so you can answer questions about it.
5. When offers arrive, compare them in the **Offer Comparison** table before replying.
6. Do the **Weekly Review** every Sunday.

**Status key:** Researching, Registered, Test scheduled, Waiting for result, Shortlisted, Interview scheduled, Waiting for outcome, Offer, Rejected, Withdrawn.

## Weekly Review (every Sunday)

- [ ] Update every status and next action in the Company Tracker.
- [ ] Add next week's deadlines and test dates to Upcoming Dates.
- [ ] Complete the Round Log for any round this week.
- [ ] Send any pending follow-ups.
- [ ] Reply to unanswered emails and messages from the placement cell.
- [ ] Spend the week's practice time on the weakest area from the [error log](../02%20General%20Round%20Preparation/Aptitude%20Round/Aptitude_Error_Log.md).
- [ ] Check [HR interview](<../02 General Round Preparation/HR Interview Round/HR_Interview_Preparation.md>) answers for each upcoming interview.
- [ ] Research each upcoming company and add a profile to `03 Company-Specific Preparation`.
